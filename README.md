
# 🎬 YouTube Homepage Clone

A responsive **YouTube Homepage Clone** created using only **HTML5** and **CSS3**. This project recreates the appearance of YouTube's homepage, including the header, sidebar, category buttons, and video grid.

## ✨ Features

- Responsive YouTube-inspired homepage
- Clean and modern UI
- Fixed header
- Sidebar navigation
- Category filter buttons
- Video thumbnail cards
- Channel information
- Responsive layout for different screen sizes
- Hover effects on buttons and video cards

---

## 🛠️ Technologies Used

- HTML5
- CSS3

## ⚠️ Note

This project is a **static frontend clone** built for learning purposes.

- No JavaScript is used.
- The search bar is for UI only and does not perform searches.
- Video thumbnails are static and do not play videos.
- No backend or YouTube API integration.
